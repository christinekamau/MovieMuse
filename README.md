

## Features

- Browse popular movies
- View movie details
- Save movies to My List

## Files

- index.html – home page
- movie.html – movie details page
- style.css – styles
- script.js – API calls and logic

## Setup

1. Get a free API key from [themoviedb.org](https://www.themoviedb.org/) (Settings → API).
2. Add it to script.js:
   js
   const API_KEY = "YOUR_TMDB_API_KEY";
   
3. Open index.html in your browser, or run a local server: `python3 -m http.server 8000
